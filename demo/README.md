# demo / —— 演示与答辩材料

## 放什么

- `demo-video.mp4`（如果太大，放网盘链接的 txt）
- `slides/` 答辩 PPT
- `screenshots/` 各页面截图（用本目录下的截图，不要用网络图）
- `script.md` 演示脚本：谁说什么、点哪里、预期看到什么

## 演示脚本（对齐《伴行.md》第十一节）

1. 本人用手机签到 → 首页显示"今日状态"。
2. 打开「生活规律」→ 展示过去 14 天的个人基线。
3. 用一个"今天没签到"的账号登录 → 首页显示"今天还没有收到你的签到记录"（**不是"危险"**）。
4. 系统弹出主动询问 → 本人选「今天比较忙」。
5. 首页出现"关怀事件已更新"。
6. 本人选「希望家人联系我」→ 家属端显示待处理事件（成员 B 的页面）。
7. 家属标记已联系 → 事件关闭。

**必须在演示时说明：手表数据是模拟的，标识为"演示数据"。**
